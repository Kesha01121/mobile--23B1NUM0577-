## Даалгавар D2 — Flutter төслийн бүтэц ба үндсэн ойлголтууд

1. **`StatelessWidget` ба `StatefulWidget`-ийн ялгаа юу вэ?**
   - **`StatelessWidget`** нь дотоод төлөв (state) хадгалдаггүй, зөвхөн гаднаас дамжуулсан `final` өгөгдлөөр нэг удаа зурагддаг өөрчлөгдөхгүй widget юм. Жишээ нь: `ShopLiteApp` нь аппын ерөнхий загвар (`MaterialApp`, `ThemeData`) тохируулдаг тул төлөв хадгалах шаардлагагүй.
   - **`StatefulWidget`** нь хэрэглэгчийн үйлдэл эсвэл өгөгдлийн өөрчлөлтөөс хамаарч дэлгэц дээрх харагдах байдлаа шинэчилж чаддаг widget юм. Энэ нь өөрөө immutable байх ба өөрчлөгдөх өгөгдлийг тусдаа `State` обьект дотор хадгалдаг. Жишээ нь: `ShopLiteHomePage` нь сагсны тоолуурыг нэмж, хасаж, тэглэдэг тул `StatefulWidget` болсон.

2. **`State` обьект гэж юу вэ? `setState()` дуудахад юу болдог вэ?**
   - **`State`** (`_ShopLiteHomePageState`) нь `StatefulWidget`-тэй холбоотой санах ойд амьдардаг обьект бөгөөд дэлгэцийн хувьсах өгөгдлийг (`int _count = 0;`) хадгалж, UI угсрах `build()` методыг агуулдаг.
   - **`setState(() { ... })`** дуудахад дотор нь бичигдсэн хувьсагчийн утга шинэчлэгдээд зогсохгүй, Flutter хөдөлгүүрт *"энэ widget-ийн төлөв өөрчлөгдсөн тул дахин зур"* гэсэн дохио өгдөг. Үүний үр дүнд Flutter `build()` методыг дахин ажиллуулж, өөрчлөгдсөн хэсгийг дэлгэц дээр шинэчилнэ.

3. **`pubspec.yaml` файл ямар үүрэгтэй вэ?**
   - Төслийн үндсэн тохиргооны файл бөгөөд төслийн нэр, тайлбар, Dart/Flutter SDK-ийн тохирох хувилбар, гаднаас татаж ашиглах сангууд (`dependencies`, `dev_dependencies`), мөн апп дотор ашиглах зураг, фонт зэрэг нөөцүүдийг (`assets`) бүртгэдэг.

4. **`lib/` болон `android/` (платформын) хавтаснууд ямар үүрэгтэй вэ?**
   - **`lib/`** нь хөгжүүлэгчийн бичсэн бүх Dart болон Flutter UI эх кодыг агуулдаг төслийн гол хавтас юм.
   - **`android/`** нь Flutter-ийн нэг кодыг тухайн үйлдлийн систем дээр ажиллах бодит апп (APK/AAB) болгон хөрвүүлэхэд шаардлагатай native тохиргоо, Gradle скрипт, `AndroidManifest.xml` зэргийг агуулдаг.

## Даалгавар D4 — Hot Reload (`r`) ба Hot Restart (`R`) туршилт

Туршилтын өмнө апп дээр `+` товч дарж сагсны тоолуурыг **`_count = 3`** болгосон.

| № | Хийсэн өөрчлөлт | Hot Reload (`r`) үр дүн | Hot Restart (`R`) үр дүн | Тайлбар |
|---|---|---|---|---|
| 1 | `AppBar`-ийн гарчгийг `'ShopLite — Миний сагс'` болгох | Гарчиг тэр дороо солигдож, тоолуур **`3`** хэвээр үлдсэн. | Гарчиг шинэчлэгдэж, тоолуур **`0`** болж тэглэгдсэн. | Hot reload зөвхөн `build()`-ийг дахин дуудаж `State`-ийг хадгалдаг. |
| 2 | `colorSchemeSeed`-ийг `Colors.teal` болгож өөрчлөх | Аппын өнгө тэр дороо ногоон болж, тоолуур **`3`** хэвээр үлдсэн. | Өнгө шинэчлэгдэж, тоолуур **`0`** болсон. | `ThemeData` шинэчлэгдэх боловч санах ой дахь `_ShopLiteHomePageState` устаагүй. |
| 3 | `int _count = 0;`-ийг `int _count = 5;` болгох | Дэлгэц дээрх тоо **`3`** хэвээр үлдсэн (`5` болоогүй). | Апп дахин эхэлж тоолуур **`5`** болсон. | `State` обьект аль хэдийн санах ойд үүссэн тул талбарын анхны утга Hot reload-оор дахин уншигддаггүй. |
